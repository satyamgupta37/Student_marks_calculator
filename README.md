# 🎓 Student Marks Calculator

A simple and beautiful **Student Marks Calculator** built using **HTML, CSS, and JavaScript**
This project allows users to enter a student's name, roll number, and marks for five subjects. It automatically calculates the total marks, percentage, average, grade, and pass/fail result.

## ✨ Features
- 👤 Enter student name
- 🔢 Enter roll number
- 📚 Enter marks for 5 subjects
- 🧮 Calculate total marks
- 📊 Calculate percentage
- 📈 Calculate average marks
- 🏆 Calculate grade
- ✅ Display Pass/Fail result
- 🔄 Reset button
- 📱 Responsive design for mobile and desktop
- 🎨 Beautiful and modern user interface

## 📚 Subjects

The calculator currently includes:
1. Mathematics
2. Science
3. English
4. Hindi
5. Computer

Each subject is calculated out of **100 marks**.

## 📊 Grading System

| Percentage | Grade |
|------------|-------|
| 90% - 100% | A+ |
| 80% - 89% | A |
| 70% - 79% | B |
| 60% - 69% | C |
| 50% - 59% | D |
| 40% - 49% | E |
| Below 40% | F |

A student must score at least **40 marks in every subject** to pass.

## 🧮 Calculations

#Total Marks
Total = Subject 1 + Subject 2 + Subject 3 + Subject 4 + Subject 5

#Average Marks
Average = Total Marks / 5
